Multiplayer Game Platform (React + Socket.IO)

This project is a real-time multiplayer gaming platform built using React.js, Socket.IO, and Express.js, featuring two complete multiplayer games:

✔ Tic-Tac-Toe (Online Multiplayer)
✔ Quiz Clash (Real-Time Multiplayer Quiz Game)

Both games support live gameplay, instant updates, private rooms, chat, and notifications.

🚀 Features
🕹️ 1. Multiplayer Tic-Tac-Toe

Real-time online matchmaking

Automatic opponent pairing

Play as Cross (X) or Circle (O)

Live board updates using WebSockets

Winner & draw detection

Integrated chat between players

Opponent disconnect handling

💡 2. Quiz Clash (Multiplayer Quiz Game)

Create custom quizzes with multiple questions

Each question supports multiple correct answers

Host and play using private room IDs

Real-time question broadcast to all players

Answer submission with score updates

Countdown timer for each question

Correct answer reveal animations

Winner announcement at game end

React-Toastify notifications for instant feedback
